# Chứng chỉ gốc

Đặt chứng chỉ gốc công khai của Supabase (`supabase-ca.crt`, tải ở Supabase: Database Settings, SSL Configuration) vào thư mục này để kết nối cơ sở dữ liệu kiểm tra chứng chỉ máy chủ (`sslmode=verify-full&sslrootcert=/app/infra/certificates/supabase-ca.crt`). Chứng chỉ gốc không phải khóa bí mật.
